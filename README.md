# Full Stack Todo App

This project is still in progress. The main features work locally, and I'm adding more as I learn. Not deployed yet.

A todo list web app with full CRUD, built with Node.js, Express, MongoDB, and EJS.

## Features

- Create, edit, complete, and delete tasks
- Set a due date and priority level for each task
- Filter by all, incomplete, or completed tasks
- See the count of remaining tasks
- Complete all tasks at once, or delete all completed tasks
- Banner showing the current date and time

## Tech

Node.js, Express, MongoDB (Mongoose), EJS, HTML, CSS, JavaScript
